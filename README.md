## Aufgabe 2: Git-Befehle demonstriert
- `git init` – Repository initialisiert
- `git add` – Dateien zur Staging Area hinzugefügt
- `git commit` – Änderungen committed
- `git push` – Auf GitHub hochgeladen
- `git pull` – (bei Teamarbeit: Änderungen herunterladen)
- `git status` – Status angezeigt
- `git diff` – Unterschiede angezeigt
- `git mv` – Datei umbenannt
- `git rm` – Datei gelöscht
